# `master` branch

Android app that implements CRUD functionality from mathematical (and not only) terms with links to each other. In fact, was intended to create summaries for any subject requiring LaTeX-like elements render. Allows user to insert various symbolic and math constructions available in [KaTeX](https://katex.org/).

App spec:

- Kotlin 1.9.22, Gradle 8.2, AGP 8.2.0, KSP 1.9.22-1.0.16
- Jetpack Compose (BOM 2023.06.01, compiler 1.5.8, Material 3), Navigation Compose 2.6.0, ViewModel Compose 2.6.1
- Room 2.6.1 (runtime/ktx/compiler via KSP), SQLite
- Accompanist permissions 0.34.0, webview 0.31.3-beta
- locally bundled KaTeX

Project goals:
- implement lemmatization for existing term auto detection
- write tests
- add license
- implement CI
